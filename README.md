# 👻 404 — СОТРУДНИК НЕ НАЙДЕН

Минималистичный сайт для офисного призрака: тёмный фон, оранжевый 404, парящий призрак в наушниках и восемь ответов на попытку вызвать сотрудника. Обычные HTML, CSS и JavaScript. Без сборки, аккаунтов посетителей, сервера, аналитики и сетевых зависимостей.

## Открыть на компьютере

Откройте `index.html` в современном браузере. Кнопка вызова и генератор QR работают и при открытии файла напрямую. В этом режиме публичную ссылку нужно ввести самостоятельно.

## Бесплатная публикация на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте **публичный** репозиторий, например `halloween`. GitHub Pages для публичных репозиториев доступен на бесплатном тарифе.
2. Через **Add file → Upload files** загрузите в корень репозитория `index.html`, `style.css`, `script.js`, `favicon.svg` и папку `vendor` с обоими файлами. Можно загрузить весь проект вместе с README и `.nojekyll`. Сохраните изменения кнопкой **Commit changes** в ветку `main`.
3. Откройте **Settings → Pages → Build and deployment**.
4. В **Source** выберите **Deploy from a branch**. В **Branch** выберите `main`, папку **/ (root)**, нажмите **Save**.
5. Дождитесь завершения публикации. GitHub покажет адрес вида `https://USERNAME.github.io/halloween/`. Используйте именно адрес страницы из раздела Pages, а не ссылку на репозиторий `github.com`.
6. Откройте эту ссылку на телефоне. Должна появиться наша шуточная страница, а не системная ошибка GitHub.

Инструкция сверена с [документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). Все пути относительные, поэтому страница работает и в подпапке репозитория. Обновления файлов в `main` публикуются автоматически. Локальная папка сама по себе не публикуется: необходимы загрузка в ваш репозиторий и включение Pages.

## QR-код для бейджика

1. После публикации откройте сайт и нажмите **QR для бейджика** внизу страницы.
2. Введите полный публичный адрес сайта. На опубликованной странице адрес подставится автоматически; последний созданный адрес сохраняется в этом браузере.
3. Нажмите **Создать QR-код**, затем **Скачать PNG**. На телефоне при необходимости сохраните изображение через меню браузера.
4. Распечатайте QR размером хотя бы **4 × 4 см**. Не обрезайте белые поля, не накладывайте рисунки, используйте чёрный код на белом фоне. PNG имеет размер от 1000 пикселей и целое число пикселей на модуль.
5. Проверьте напечатанный код камерой телефона, желательно через мобильную сеть. Он должен открывать именно страницу с призраком. Не меняйте адрес сайта после печати.

Генератор кодирует **непосредственно введённый URL**, без сервисов перенаправления и промежуточных экранов. Окно генератора по умолчанию закрыто. Проверка формы отсекает локальные адреса, но не проверяет доступность сайта — проверьте ссылку перед печатью. Указанный «404» — часть дизайна; `index.html` является обычной успешной страницей.

При желании задайте постоянный адрес в начале `script.js`:

```js
const PUBLIC_SITE_URL = 'https://USERNAME.github.io/halloween/';
```

Эта настройка имеет приоритет над сохранённым адресом. Нельзя создать рабочий публичный QR до получения постоянной ссылки на опубликованный сайт.

## Файлы и настройка

- `index.html` — текст, иллюстрация призрака, окно QR.
- `style.css` — адаптивная вёрстка, цвета и CSS-анимации. Цвет акцента: `--orange`.
- `script.js` — ответы на вызовы, настройки ссылки, создание и скачивание PNG.
- `favicon.svg` — иконка сайта.
- `vendor/qrcode.js` — локальная библиотека [qrcode-generator 1.4.4](https://github.com/kazuhikoarase/qrcode-generator), Kazuhiko Arase, MIT. Лицензия: `vendor/LICENSE-qrcode`. Сохраните её при распространении.
- `.nojekyll` — публикация файлов без обработки Jekyll.

Тексты ответов меняются в массиве `replies`. Для анимаций учтена настройка «Уменьшение движения»; окно закрывается Escape, фокус остаётся внутри диалога и возвращается на кнопку после закрытия. Внешние шрифты, изображения и CDN не используются. Генератор работает локально, никуда не отправляя введённый адрес.
